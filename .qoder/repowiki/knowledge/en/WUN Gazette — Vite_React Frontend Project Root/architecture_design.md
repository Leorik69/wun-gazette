This is the top-level project manifest for a single-page application. `index.html` is the Vite entrypoint (loading `/src/main.tsx` as an ES module) with Google Fonts (Fraunces + Outfit) preconnected. `vite.config.ts` registers only the `@vitejs/plugin-react` plugin, keeping the build pipeline minimal. `tsconfig.json` targets ES2022, uses `moduleResolution: "bundler"`, enables strict mode plus `noUnusedLocals`/`noUnusedParameters`, and sets `jsx: "react-jsx"` so JSX compiles without explicit imports. `vercel.json` declares the project as a Vite framework with `dist` as the output directory. Runtime dependencies are React 19, Three.js 0.187, and lucide-react icons; `@types/three` provides typings. A small Node test runner (`node --test`) is wired for `src/heroWelcome.test.mjs`. The `emblem.svg` asset sits at the repo root alongside the HTML.
